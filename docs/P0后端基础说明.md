# P0 后端基础说明

## 成员 A 当前交付范围

本阶段只完成后端基础，不在本机搭建前端，也不实现 P1-P4 的业务接口。

已交付内容：

- Django 项目结构：`backend/manage.py`、`backend/config/`、`backend/apps/`。
- 预留 app：`common`、`users`、`courses`、`progress`、`exams`。
- DRF 配置：统一认证入口、分页类、异常处理。
- MySQL 配置：通过 `.env` 读取数据库连接，使用 `PyMySQL` 驱动。
- CORS 配置：允许成员 B 的 Vite 开发地址访问后端。
- media 配置：上传文件未来统一放 `backend/media/`，实际文件不提交 Git。
- 健康检查：`GET /api/health/`。
- 接口文档：`docs/API接口文档.md`。

## 验收方式

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python manage.py check
python manage.py migrate
python manage.py runserver
```

访问：

```text
http://127.0.0.1:8000/api/health/
```

预期返回：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "status": "ok",
    "time": "..."
  }
}
```
